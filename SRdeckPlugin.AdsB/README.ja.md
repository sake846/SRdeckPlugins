# SRdeckPlugin.AdsB

安定プラグインIDは `adsb`。1090 MHz Mode S拡張スキッタを受信します。

## 受信経路

- 1.85 MHz帯域、4 MS/s出力の1090 MHz標準チャネルを優先します。
- ホスト入力には2 MS/s以上を要求し、不足する同調要求は拒否します。
- Mode Sプリアンブルを検出し、PPM復調とCRC検証を行います。

## 機能

DF17/DF18、機体識別、高度、速度、トラック、垂直速度、even/odd CPR位置を解析します。
WPFワークスペースで受信履歴、機体一覧、設定、結果通知、CSV/JSONエクスポートを利用できます。

## ビルド

互換するSRdeckプラットフォームパッケージを用意し、`SRdeckPlugins.sln`のRelease構成をビルドしてください。
