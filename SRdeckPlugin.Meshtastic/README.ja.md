# SRdeckPlugin.Meshtastic

安定プラグインIDは `meshtastic`。Meshtastic LoRaパケットの受信・復号を提供します。

このソースはソースレベルの開発用として`SRdeckPlugins`に公開します。MeshtasticのDLLは
SRdeckの実行ファイルパッケージに含めません。

## プロファイル

LongFast、LongModerate、LongSlow、MediumFast、MediumSlow、ShortFast、ShortSlowに加え、
250 kHz、125 kHz、混在動作向けの自動拡散率プリセットを提供します。

## 機能

LoRaチャネル抽出、チャープ復調、FEC/CRC検証、Meshtasticパケット解析を行います。条件指定モードでは、
選択した先頭スロットを48 kHzモノラルPCMへFM復調して音声モニターできます。探索モードではFMモニターを
処理しません。WPFワークスペースでプロファイル設定と周波数オーバーレイを利用できます。

### SNR / RSSI 表示

SNR は、プリアンブルの繰り返し相関から信号電力と雑音電力を分離し、選択した
LoRa帯域（250/125 kHz）を基準に算出する推定SNRです。FFTピーク比（旧Q）ではなく、
負の値も表示します。定常雑音と安定したチャネルを仮定するため、フェージングや同期した
混信、サンプルクロック誤差では偏りが生じます。公式LoRaチップの報告値との一致は保証しません。
十分なプリアンブルがない場合や、Qしか保存されていない旧履歴は `SNR —` と表示します。
検出・同期判定用のFFTピーク比としきい値は内部に保持します。

RSSI は同じプリアンブルの受信帯域内平均電力（信号＋雑音）の推定値です。
ホストの瞬時の受信メーター値ではなく、各パケットのIQ電力を使用します。
SRdeckの受信レベル校正でdBFSからdBmへ換算するため、精度は校正と受信ゲインに依存します。
ホストの校正情報が取得できない環境では単位をdBFSと明記します。
RSSIのない旧履歴は `RSSI —` と表示し、過去の値を現在の校正で換算し直しません。

### シンボル判定の精密化

プリアンブル捕捉後は、既存FFTの整数ビン電力と、ピーク両隣の半ビン位置だけを
計算する局所DFTでピーク位置を精密化します。2倍ゼロパディングFFTと同じ補間点を
使いますが、ゼロパディングや大きなFFTの追加実行は行いません。
基準・同期・データ・ソフト判定候補に共通の方式を使い、IQバッファの再利用と
直前の候補のキャッシュで、シンボルごとのメモリ確保や主ピークの重複計算を避けます。
探索しきい値とCRCの合格条件は維持し、録音専用の固定補正値や、データ判定に基づく
自動追従は追加していません。

## 受信履歴

JSON Lines履歴は設定した保存日数に加え、最大100,000件・128 MiBの範囲で新しい受信を保持します。
上限に達した場合は古いレコードから削除します。受信中と保存日数変更時の保持処理は背景で実行します。

## ビルド

互換するSRdeckプラットフォームパッケージを用意し、`SRdeckPlugins.sln`のRelease構成をビルドしてください。
