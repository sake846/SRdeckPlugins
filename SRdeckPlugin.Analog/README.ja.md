# SRdeckPlugin.Analog

安定プラグインIDは `analog`。AM、FM、SSBの音声復調を提供します。

## プロファイル

- AM（振幅変調）
- FM（周波数変調）
- SSB（単側波帯）

## 機能

プラグイン独自の音声ワークスペースと設定画面で、プロファイル選択、同調、スケルチ、AGC、
音声フィルター、復調チャネルに絞った直前3秒のIQプリトリガー録音と、内部サンプルレートで連続IQ録音を扱えます。録音ファイルは通常10分ごと、WFMでは1分ごとに分割します。保存したIQ WAVは設定画面から選択して再生でき、分割録音は先頭ファイルを選ぶと連続再生します。ヘッドレス処理にも対応します。

連続IQ録音はレート変換後、チャネルフィルター前の複素IQを保存します。間引き時はCIC補償も適用されます。直前3秒のプリトリガー録音はチャネルフィルター後のIQを保存します。

連続IQ録音の付随JSONには、サンプル位置に対応する実時刻、受信テレメトリーのdBm換算補正とその変更、不連続点を`Timeline`として保存します（スキーマ2）。保存したIQ振幅は変更せず、SRdeckPlayで時刻・電力・欠落位置を復元するために使用します。

## ビルド

互換するSRdeckプラットフォームパッケージを用意し、`SRdeckPlugins.sln`のRelease構成をビルドしてください。
