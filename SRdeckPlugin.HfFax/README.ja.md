# SRdeckPlugin.HfFax

安定プラグインIDは `hffax`。HF気象無線模写（Weather Fax / Wefax）をIQから
受信し、APT開始・停止信号を検出してIOC 576/288のグレースケール画像を生成します。

割当周波数を中心とする3.0 kHz帯域を12 kS/sで処理し、F3Cの-400 Hz（黒）～
+400 Hz（白）を画像化します。60/90/120 LPM、手動受信、傾き・横位置補正、
モニター音声、PNG保存に対応します。FM復調後の映像にはOFF/600/1200/1800 Hzの
VBWフィルターを選択でき、既定値は1200 Hzです。

画像データとPNG出力はIOCから求めた走査線幅（`π × IOC`）の原寸を保持し、画面上で
のみ縮小表示します。完成した画像は時系列履歴へ永続化され、次回起動時にも復元されます。
手動開始でライン原点がずれた場合は、横位置補正を変更すると受信を止めずに既受信ラインと
以後のラインをまとめて循環移動できます。
受信開始後に位相信号を検出できた場合は、その基準を保持し、後から手動開始しても次の完全な
走査線から横位置を自動補正します。位相信号より後から受信を始めた場合は手動補正が必要です。
「ライン毎同期補正」を有効にすると、画像受信中もライン境界の同期パルスへ追従します。
同期パルスの欠落中もライン位相を保持し、再検出時にライン位置と走査周期を補正します。
同期状態、検出数、欠落補間数、受信周期偏差は診断タブで確認できます。画像中に同期パルスを
送らない局では、この設定を無効にしてフェージング測定値と手動ppm補正を使用できます。

## ビルド

互換するSRdeckプラットフォームパッケージを用意し、`SRdeckPlugins.sln`のRelease構成をビルドしてください。
