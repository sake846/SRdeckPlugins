# SRdeckPlugin.Cw

安定プラグインIDは `cw`。10/20/50 kHz帯域のマルチシグナルCWスキマーと適応モールス復号を提供します。

## 受信経路

- 選択可能な10/20/50 kHz帯域（10/20/50 kS/s）の標準IQチャネルを使用します。
- 帯域内FFTとピーク追尾による複数CW信号の同時検出を行います。
- 変動する通信速度（5〜60 WPM）に対応する適応モールスタイミング復号器を搭載しています。
- 自動コールサイン抽出とアクティビティ追尾に対応します。

## 機能

- ウォーターフォール注釈および周波数オーバーレイ表示
- 信号診断・SNR算出を伴うリアルタイムテキスト復号
- 選択信号のモニター音声生成
- 直前10秒間のIQプリトリガー録音
- JSONLによる復号履歴の永続化およびCSV/JSONエクスポート
- 選択したキャリアを800 Hzへ移して聞くモニター音声
- 文字タイミングに基づく復号信頼度と言語メタデータ

復号履歴は文境界または信号終了時に確定し、保持件数は「表示行数」設定に従います。
和文モードで国際モールス数字と符号が重複する文字（例: セ/1）は仮名を優先します。
国際モールスの数字列はラタで欧文へ戻してから送信する運用を想定しています。

## ビルド

互換するSRdeckプラットフォームパッケージを用意し、`SRdeckPlugins.sln`のRelease構成をビルドしてください。
