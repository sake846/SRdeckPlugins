# SRdeckPlugin.MaritimeVhf

安定プラグインIDは`maritime-vhf`です。国際VHFの音声をNFMで受信し、DSC専用CH 70を同時監視して、有効なDSC呼出で指定された作業チャンネルへ受信機を自動追尾します。受信専用で、送信機の制御やDSC確認応答の送信は行いません。

## 受信機能

- 国際VHF 25 kHzチャンネル表と、船舶送信側／海岸局送信側の選択
- 48 kS/s NFM音声復調、ディエンファシス、スケルチ、モニター音声
- CH 70（156.525 MHz）の1300/2100 Hz AFSK、1200 bit/s DSC復号
- 10ビット符号検査、時間ダイバーシティ復元、ECC検証
- 遭難、個別、グループ、全船、海域呼出のMMSI、優先度、位置、作業CH解析
- DSC履歴、重要度別通知、診断、周波数オーバーレイ

AIS 1（161.975 MHz）とAIS 2（162.025 MHz）は意図的に対象外です。AISの受信には`SRdeckPlugin.Ais`を使用してください。

## DSC自動追尾

`有効なDSCの作業チャンネルを自動追尾`を有効にすると、符号、時間ダイバーシティ、ECCを通過した呼出だけを追尾候補にします。

- 自局MMSIが空欄: 受信した有効な呼出を追尾
- 自局MMSIを設定: 全局・遭難呼出と自局宛の呼出だけを追尾
- 作業CHがある呼出: 指定された船舶側／海岸局側を含めて選局
- 作業CHのない遭難呼出: CH 16へ移動
- `追尾解除`: 通常監視チャンネルへ手動復帰
- `無信号後の自動復帰`: 音声キャリアがない状態が設定時間続くと復帰（0秒で無効）

これは受信機内の自動選局です。GMDSS設備としての送受信、遭難警報、確認応答、遭難通信手順を代替しません。

## 最初の受信

1. 156～163 MHz付近に対応するアンテナを接続します。
2. `MODE`で`国際VHF`を選びます。
3. 音声チャンネルと受信側を選び、`CH 70 DSCを同時監視`を有効にします。
4. 必要なら9桁の自局MMSIと自動復帰秒数を設定します。
5. `Start`を押し、音声CHとDSC CH 70のオーバーレイを確認します。
6. `DSC履歴`と`診断`で復号、追尾、選局状態を確認します。

選択した音声周波数とCH 70をSDRの入力帯域へ同時に収められない場合、音声受信を優先してDSC同時監視を一時停止し、その状態を画面へ表示します。特にデュプレックスチャンネルの海岸局送信側では周波数差が大きくなるため、十分なRATEが必要です。

## 主な設定

| 設定 | 既定値 | 有効範囲／意味 |
|---|---:|---|
| 音声チャンネル | CH 16 | CH 70とAIS 1/2を除く国際VHF音声CH |
| 受信側 | 船舶送信側 | デュプレックスCHでは海岸局送信側も選択可能 |
| モニター音量 | 80% | 0～100% |
| スケルチしきい値 | -110 dBm | -160～-20 dBm |
| CH 70同時監視 | ON | 入力帯域へ収まる場合に監視 |
| DSC自動追尾 | ON | 有効な呼出の作業CHへ受信機を選局 |
| 自局MMSI | 空欄 | 任意の9桁。空欄では宛先を限定しない |
| 自動復帰 | 60秒 | 0～600秒、0で無効 |

## ビルド

互換するSRdeckプラットフォームパッケージを用意し、`SRdeck.sln`のRelease構成をビルドしてください。公式プラグイン配布定義と組み込みDLLコピー対象へ登録済みです。
