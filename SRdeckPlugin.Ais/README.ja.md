# SRdeckPlugin.Ais

安定プラグインIDは `ais`。2チャネル海上AIS GMSK受信プラグインです。

## 受信経路

- AIS 1（161.975 MHz）とAIS 2（162.025 MHz）を監視します。
- 両チャネルの同期した標準チャネルIQブロックを利用します。
- GMSK復調、フレーム検出、HDLC/FCS検証、AISメッセージ解析を行います。

## 機能

船舶ターゲットと受信履歴を管理し、WPFワークスペース、音声モニター、周波数オーバーレイ、
結果通知、CSV/JSONエクスポートを提供します。

## ビルド

互換するSRdeckプラットフォームパッケージを用意し、`SRdeckPlugins.sln`のRelease構成をビルドしてください。
