# 未知信号の解析ワークベンチ

プラグイン管理で有効化し、MODEで「未知信号の解析ワークベンチ」（ID: `signal-workbench`）を選び、周波数を選局して受信を開始します。既知の復調方式を指定せず、選択した帯域の特徴を観察できます。

## 操作

- 左ペイン、周波数カタログ、スペクトラムで解析する中心周波数を選択します。
- 解析帯域を6 / 12.5 / 25 / 50 / 100 / 200 kHzから選び、「帯域を適用」を押します。既定値は25 kHzです。
- 「表示を保持」で現在のグラフと候補を固定できます。受信・解析は続き、解除すると次の解析窓から更新します。
- 選局、帯域・入力レート変更、IQ欠落、再Startで解析窓と表示保持をリセットします。設定はホストのプラグイン設定ストアに保存します。

ホストの標準チャネル化処理で周波数変換・帯域制限を行い、帯域の4倍のレートで解析します。入力レートが不足する場合はホストがRATE変更を要求することがあります。提供できない帯域への変更は拒否し、元の解析設定に戻します。

## 表示の読み方

| 表示 | 内容・制約 |
|---|---|
| コンスタレーション | RMS正規化した未同期のIQを最大1,536点表示。搬送波・クロック同期や判定フィルターを通したシンボル点ではありません。遷移点・回転も表示されます。 |
| 入力レベル | チャネルIQの平均複素電力をdBFSで表示。RFの校正済みdBmではありません。 |
| 周波数偏移分布 | 隣接IQの位相差 `arg(x[n] conj(x[n−1])) × Fs / (2π)` の128ビン分布。平均電力の−30 dB未満のサンプルを含む対を除外します。 |
| 分布の範囲 | 1–99%点の大きい方の絶対値の1.1倍を左右対称の範囲とします。最小4 FFTビン、最大±Fs/2。範囲外は端のビンに集計します。 |
| 平均・5–95%幅 | 有効な瞬時周波数の平均と分位点間の幅。変調の影響を含み、搬送波誤差・占有帯域の確定値ではありません。 |
| FSK解析 | 2 / 4 / 8個の等間隔なトーン候補を探索。選局点基準の各周波数、出現割合、標準偏差、中心ずれ、隣接間隔、外側偏移を表示します。分布上の補助線は各トーンの推定位置です。 |
| 周波数判別波形 | 解析窓の先頭1,024点の瞬時周波数を時間順に表示。縦軸は偏移分布と同じ範囲で、範囲外はクリップし、無効なサンプル対では線を切ります。クロック同期・フィルター処理前の波形です。 |
| シンボルレート候補 | 包絡電力、平均位相差からの位相変化、位相差の変化量の二乗に対する周期ピーク。FSKトーンを検出した場合は、最近傍トーンの切り替わりを同じ重みで数えた周期ピークも調べます。最大5件を表示します。 |
| h (FSK) | 隣接トーン間隔を各レート候補で割った変調指数候補。2FSKでは `h = 2Δf / Rs`（Δfは片側偏移、Rsはシンボルレート）。トーン未検出時は表示しません。 |

解析窓は16,384サンプルです。窓が足りない間はデータ待ちを表示します。計算は入力の約250 msごと（窓が長い場合は1窓ごと）に行い、UI更新は最新結果にまとめます。表示保持中もメモリや履歴は増えません。

候補探索では平均を除去してHann窓・FFTを適用し、4 FFTビン以上、Fs/4未満（4サンプル/シンボル超）の局所ピークを検査します。スペクトル中央値から12 dB以上、近傍3ビンが探索スペクトル電力の1.5%以上を持つピークを採用します。近接候補をまとめ、ピークの強さ順に表示します。このdB値は確率・SNRではありません。

周期性が明瞭でない方式、短いバースト、低SNR、多重信号では候補が出ない場合があります。高調波・副調波・アナログ変調の周期が候補になる場合もあります。方式の自動判定やビット復号は行いません。

### FSK解析の条件と制約

有効な位相差が512組以上ある窓を対象に、表示用とは別の256ビンの分布を作ります。
1–99%点の幅が8 FFTビン以上のとき、その範囲を両側へ10%広げて5点で平滑化するため、選局点からずれた狭いトーン間隔も探索できます。
明瞭に分離したピークが2 / 4 / 8個あり、隣接間隔が4 FFTビン以上、間隔のばらつきが20%以内の場合に候補とします。
さらに、各トーンの±1/4間隔に有効なサンプル対の4%以上が入り、合計65%以上を説明し、
各トーン付近の標準偏差が間隔の10%以下となることを確認します。条件を満たさない窓ではFSK候補を表示しません。

中心ずれは両端トーンの中点です。出現割合は有効なサンプル対に対する各トーン付近の比率で、
遷移中の値などは含まれず、合計が100%にならない場合があります。標準偏差も各トーン付近の値だけから計算し、SNRを表すものではありません。
GFSK・GMSKなどで周波数の遷移が長くトーンが重なる場合や、使用されないトーンがある場合は、想定したトーン数を検出できないことがあります。
その場合も判別波形と偏移分布を観察できます。等間隔の複数信号も候補になり得るため、「FSK様」は方式の確定を意味しません。
レートの高調波・副調波に対応するhも候補値です。ビット列、シンボルの割り当て、通信規格の判定は対象外です。

非線形処理からクロック周期を観察する考え方の参考: [Moonほか、Timing Recovery in CMOS using Nonlinear Spectral-line Method (1996)](https://web.engr.oregonstate.edu/~moon/research/files/cicc96.pdf)。本プラグインは探索用の候補表示であり、論文の同期回路の実装ではありません。

## ビルド・検証

公開版の`with-plugins` ZIPには本プラグインのDLLを同梱します。`host-only` ZIPには含みません。
Windows x64と.NET 10 Desktop Runtimeを使用し、ホストとプラグインは同じリリースの組み合わせにしてください。

公開ソースから単独ビルドする場合は、同じリリースのプラットフォームNuGetパッケージ4個を
`SRdeckPlugins`の`platform-packages`へ配置し、リポジトリのルートで実行します。
パッケージの入手手順はルートの[README](../README.ja.md)を参照してください。

```powershell
dotnet build SRdeckPlugin.SignalWorkbench\SRdeckPlugin.SignalWorkbench.csproj -c Release -p:Platform=x64
```

出力先は`SRdeckPlugin.SignalWorkbench/bin/x64/Release/net10.0-windows/win-x64`です。
`SRdeckPlugin.SignalWorkbench.dll`を`SRdeck.exe`と同じフォルダーへ配置し、SRdeckを再起動してプラグイン管理で有効化します。
本プラグイン固有のネイティブDLLはありません。開発リポジトリではホストのビルド時にコピーします。

合成搬送波の周波数符号・電力、QPSKのクロック候補、2/4/8FSKのトーン・レート・h候補、雑音・無信号・アナログFMの棄却、IQ不連続、帯域拒否、表示保持、再Startを回帰テストします。
[検証記録](TESTING.ja.md)も参照してください。実機での未知信号の方式同定精度は保証しません。
