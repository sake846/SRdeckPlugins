# SRdeckPlugin.WiSun

Stable plugin ID: `wisun`. 920 MHz Wi-SUN / IEEE 802.15.4g SUN FSK demodulator.

## Profiles

Supports Wi-SUN FAN Mode 1b/2/3/4/5, HAN A/B route profiles, and custom
settings. Channel plans and PHY profiles are exposed as live tuning profiles.

## Features

Performs SUN FSK synchronization and PHY/MAC parsing, provides frequency
overlays and packet export, and supports headless processing.

## Build

Build the matching `SRdeckPlugins.sln` release solution with the compatible
SRdeck platform packages.
